# Repair shop with Next.js Application

This project is a modern web application built with the following technologies and tools:

## Features and Technologies

- **[Next.js 15](https://nextjs.org/)**: A React framework for building fast, server-rendered applications.
- **[Tailwind CSS](https://tailwindcss.com/)**: A utility-first CSS framework for styling.
- **[Sentry](https://sentry.io/)**: Error tracking and monitoring to ensure application stability.
- **[shadcn/ui](https://shadcn.dev/)**: A collection of accessible and customizable UI components.
- **[Kinde](https://kinde.com/)**: Authentication and user management made simple.
- **[Neon](https://neon.tech/)**: A serverless PostgreSQL database for scalable and efficient data storage.
- **[Drizzle ORM](https://orm.drizzle.team/)**: A lightweight and type-safe ORM for database interactions.
- **[Zod](https://zod.dev/)**: A TypeScript-first schema declaration and validation library.
- **[React Hook Form](https://react-hook-form.com/)**: A performant and flexible library for managing forms.
- **[Next Safe Action](https://github.com/next-safe-action)**: Enhances security for server-side actions in Next.js.
- **[TanStack Table](https://tanstack.com/table)**: A powerful table library for building data grids.
- **[Vercel](https://vercel.com/)**: Deployment platform for hosting and scaling your Next.js application.

## Deployment

This application is deployed on **Vercel**, ensuring fast and reliable performance.

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/your-repo/nextappv1.git

   ```

2. Install dependencies
   ```bash
   npm install
   ```
3. Run the development server
   ```bash
   npm run dev
   ```
